API 테스트는 httpx ASGI transport로 실제 FastAPI 라우트와 SQLAlchemy DB 작업을 호출합니다. 네트워크·reverse proxy·MySQL 서버 자체를 테스트한 것은 아닙니다. 스킵된 테스트를 통과한 것처럼 표시하지 않습니다.

## 14개 기본 테스트가 확인하는 내용

1. bcrypt 해시 저장, 비밀번호 필드 응답 제외.
2. 이메일 중복과 대소문자 정규화.
3. 한글 비밀번호 UTF-8 바이트 제한과 오류 응답에서 입력 제거.
4. 잘못된 비밀번호 및 `is_admin` 주입 거부.
5. refresh 회전·이전 토큰 재사용 거부·Origin 검사·로그아웃 세션 폐기.
6. 만료/변조 JWT 거부.
7. 상품 검색·페이지 범위·인증/관리자 권한·입력 필드 제한.
8. 사용자별 카트 격리.
9. 서버 가격 사용·주문 가격 스냅샷·중복 키 처리·카트 삭제.
10. 주문 중 두 번째 상품 품절 시 앞선 재고 차감까지 롤백.
11. 타인 주문 조회/취소 차단·반복 취소에도 재고 1회 복구.
12. 관리자 상품 편집 version 충돌·비공개·감사 기록.
13. 허용 주문 상태 전환·무료 배송 임계값.
14. 인증 요청 빈도 제한.

MySQL 전용 테스트는 서로 다른 회원이 마지막 재고 1개를 동시에 주문하는 경우, 같은 회원이 같은 idempotency key를 동시에 제출하는 경우입니다.
