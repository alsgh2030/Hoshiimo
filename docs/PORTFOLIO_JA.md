# Hoshiimo — バックエンド開発ポートフォリオ

## 概要

茨城県の干し芋店「塚田商店」を題材にした、ECサイトの学習用プロジェクトです。将来、店舗運営を技術面から支えることを目標に、React・FastAPI・MySQLで購入フローと管理機能を実装しています。

公式サイトを置き換えるものではなく、実際の決済・配送は行いません。商品情報と価格はデモ用です。

## 実装範囲

- 会員登録、bcryptによるパスワードハッシュ、JWT認証、refresh tokenの更新。
- 商品検索、カテゴリ、ページネーション、ユーザーごとのカート。
- サーバー側での価格計算、注文時点の商品情報の保存。
- 注文作成・在庫更新・カート削除を同一トランザクションで処理。
- Idempotency-Keyによる注文の重複抑止。
- 管理者の権限制御、在庫編集時のバージョン確認、操作履歴。
- Alembicマイグレーション、pytest、MySQL向けCI設定。

## 技術的に説明したい点

在庫更新と注文保存の途中でエラーが発生したとき、どこまで取り消す必要があるかを考えてトランザクションを設計しました。また、商品価格が変更されても過去の注文が変わらないよう、注文項目に商品名と単価を保存しています。

認証情報をAPIレスポンスに出さないこと、他のユーザーの注文にアクセスできないことをテストしています。管理画面では、古い在庫情報で新しい在庫を上書きしないよう、バージョン番号を使っています。

## 検証状況と今後

SQLiteを使ったAPIテスト14件とフロントエンドビルドを確認しました。MySQLの同時注文テスト2件は作成済みですが、この作業環境では実行していません。既存GitHubリポジトリへの統合、MySQL上での検証、HTTPS環境でのブラウザテストは次の作業です。
